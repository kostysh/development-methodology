# Solo decisions and operation metrics, 5.0.1 candidate

On 2026-11-20 a local Linux trial installed the candidate tarball offline.
Its SHA-256 was
`f2b59a5f888336e8f5febdc5f013cd260b432b2b2809beb9b7e96dc50198f58a`.
The commands ran with Node.js 24.15.0. The workspace trial used Codex CLI
0.171.0. The project, decision records and measurements belonged to this trial.

## Shared-account decisions

The installed command applied a delegated proposal, then held a second
proposal at the cap of one. Recording the owner's chat message released
the slot. A subsequent message changed the choice. Replaying the first
message retained the correction and both references. The bound PR stayed
held. A legacy version-1 receipt and a shared writable inbox also kept it
held when the owner UID was absent, matched the caller or named a different
UID from the actual owner.

## Independent coordinator

The positive case ran the installed coordinator with its ordinary non-root
UID. A fixture with a different kernel UID owned the policy, inbox and
their parent. The coordinator's write-access checks for both files failed.
It installed genuine fixture batches, enforced a pending hold, and allowed
a corrected decision only on its verified, rebound revision. Removal of
the source receipt held the gate. The original owner-first, train-first,
ordinary publishing and interrupted-pusher cases exercised the profile lock
through local Git publication. Two decision cases and one publication case
passed, with zero failures. These are isolated OS, CLI and Git checks.

## Workspace operation metrics

A fresh Git project ran the installed collector under
`codex sandbox -c 'sandbox_mode="workspace-write"'`. The profile and private
journal were outside the workspace and the temporary directories writable
to that sandbox. A direct journal append failed. The wrapped command still
ran once and returned 7. A second command used the operation spool, a fresh
attempt key and an unissued suite key. It ran once and returned 3. The
authoritative journal was absent until the first coordinator import.

The spool supplied seven observations: task start, decision request, block
and resolution, runner start and finish, and a real Git post-rewrite hook
from an amendment. The first import recorded seven events and zero gaps.
Replay recorded zero new events and seven repeats. The owner separately
recorded acceptance. The summary showed 463 ms elapsed, 77 ms blocked and
one measured test. The mode of the authoritative journal was 0600. Both
temporary data directories were removed. All three packed operation
regressions passed, including validation of task scope, clocks, event shape,
owner authority and executable argument boundaries.

These durations describe one trial. Production adoption and changes in
delivery time require measurements from an adopting project.
